冻结校验器的旧 schema 只允许 integer/thousands/fraction/multiplier/ranking/level，缺少 percent。因此正式标注记录 percent，另生成冻结运行副本，仅将这一条的元数据枚举映射回 integer 以通过旧校验；真值、图片、框和审核信息完全相同。`number_form` 不决定识别或数字评分，数字语义由原文字解析。这一兼容处理没有修改冻结代码、字符集、模型、阈值或评分。两份输入 SHA 和唯一字段差异均在[运行后核验记录](../out/ocr-audit/b1c-independent-evidence/provenance-verification.json)中绑定。

`4830 / 4830` 与 `4830/4830` 在冻结解析器中均解析为 fraction(4830, 4830)。本轮该条实际输出 `4830/4830`，语义评分正确；`742%` 实际输出也为 `742%`，按 percent(742) 正确处理。修框后的 `任務` 同样识别正确。
