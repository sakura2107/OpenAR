# B1b 新验收集计划（尚未采集）

旧 `test` 从 B1b 起仅作为回归集。新验收集单独建目录，不能与旧 tune/test 混合计分，也不能在选择模型、线程、数字参数时使用。

两服各约 60 条界面文字、40 条数字；按新截图/页面分组，避免同一画面连续帧重复计数。保留描边、小字、半透明，以及整数/千分位、a/b、xN、百分比和排名区间。数字优先覆盖斜杠、百分号、x1、重复数字，但不只选择模型已检测到的区域。

缺场景为日服竞技场结算、繁中每日奖励、繁中竞技场结算，仅在以后自然可见时补，不为采集开战、领奖或消耗资源。用户当前未要求开始采集，因此此目录还没有新截图或验收结果。

采集命令与 B1 相同，使用 `scripts/capture-ocr.ps1`，输出到全新的批次目录。采集前记录当时选定的模型、配置、DLL、评分版本和 SHA256；冻结后才采新图。采集与逐条标注完成后，先运行冻结候选一次并保存全部结果，再查看错误。若按这批错误调整参数，该批自动降为回归集，需要另采新验收集。

评分用 `scripts/ocr_report.py` 的 B1b 口径，同时输出原始串、规范化文字、封闭集和数字语义结果。封闭集按语言/场景分组，规范化文本去重，编辑距离并列或拒识均算失败；场景标签已知，因此它不代表未知画面的场景分类率。必须记录候选词表来源，不能将事后人工纠错当作 OCR 输出。

约 40 条数字要求 99.5% 意味着这批必须 40/40；60 条文字要求 97% 意味着至少 59/60，封闭集要求 99% 则需 60/60。这些都是小样本点估计，不声称已证明任意新画面都达到该总体准确率。
